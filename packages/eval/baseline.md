`roundtrip_after_mutation_rate` = distinct synthetic values recovered /
values a correct restorer owes. Probe classes owe nothing, so they read
`n/a`; their contract is the identity table below.

- `ok` — surface mutation, fully recovered.
- `baseline-gap` — known-lossy today. Plan Phase C (levers L3/L4) has to move these; this number is what proves it moved.
- `probe-withheld` — the mutation re-pointed or invented a token and nothing came back. Correct, fail-closed.
- `category-blind-repair` — the token's own value came back, but the repair accepted a category that did not match. Reported, not fatal.
- `regression` / `invariant-violated` — failures; the runner exits non-zero.

## Notes

**3 — hash-char-substitution** (one hash character substituted, length preserved)

- recovered by the L4 single-candidate edit-distance repair; a drop here means repair regressed or turned ambiguous

**4 — hash-length-change** (one hash character inserted or deleted)

- length-changing hash damage; recovered only via the repair-only candidate scan plus the single-candidate edit-distance rule

**5 — markdown-escape** (every underscore backslash-escaped)

- backslash-escaped underscores hide the token from both matchers; the candidate scan tolerates the escapes and the normalized form is an exact vault key

**7 — sse-delta-split** (split across simulated SSE deltas at every offset)

- every split offset reassembled losslessly and released whole tokens through the real proxy stream buffer

**11 — category-rename** (category renamed to a synonym that was never minted)

- renamed category names no vault entry; recovery must stay fail-closed (I1 requires a category match)

**12 — category-swap** (category replaced by another live one, hash kept)

- hash survives under a different category; the vault key is a miss and must stay one

**13 — hash-swap** (hashes of two live tokens exchanged (false-restoration probe))

- hashes rotated between live tokens; no token may resolve to another entry's value (I1)

**14 — invented-token** (wholly invented token appended (hallucination probe))

- hallucinated token; must be counted as observed-and-unknown, never resolved
